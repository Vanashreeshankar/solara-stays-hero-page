# Solara Stays — Boutique Hotel Hero Page

A responsive landing page concept for a boutique hotel,
designed to showcase an immersive visual experience.

## Project Overview

This project focuses on the hero section of a boutique
hotel website, combining responsive frontend development,
3D motion and visual storytelling.

## Features

- Responsive layouts for desktop, tablet and mobile
- Interactive 3D hanging chair animation
- Custom visual assets and background design
- Responsive navigation and booking interface
- Smooth visual interactions

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Spline 3D

## Project Scope

This repository contains the homepage/hero section demo,
not a complete hotel website.

Additional pages and booking functionality are potential
future extensions.

## Run Locally

1. Clone the repository.
2. Navigate to the frontend folder.
3. Install dependencies.
4. Start the development server.

## Future Scope

The current implementation focuses on the responsive homepage hero section.
The following enhancements are planned for future development:

- Develop the remaining website pages, including rooms and suites,
  experiences, about, gallery and contact.
- Build a complete hotel booking and reservation system.
- Develop REST APIs using Node.js and Express.js.
- Integrate MongoDB for database management.
- Implement backend functionality for bookings,
  availability and customer management.
- Connect the frontend with backend services.
